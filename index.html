File Library backup and restore

Create a separate encrypted .p8lib backup containing the complete file copies, folder structure, categories, archived items, and Trash. The existing p8Work Master Backup does not include this File Library. This release supports up to 160 MB of imported files total so each library can be completely backed up.

Backups download to your computer; keep them in an employer-approved secure location. Before deleting originals, test a restore and verify the copies. The 160 MB storage limit prevents imports that the current backup format cannot safely accommodate.

About p8Work

p8Work keeps its work tools separate while providing one launcher, offline application shell, update path, and protected Master Backup system.

p8Work

Offline-capable work tools and private local records

Tool data is stored locally in this browser profile unless you export it yourself. Hosting p8Work on GitHub Pages does not upload local tool records to the repository. Clearing browser/app data can remove local files and records. Back up both the four tools (Master Backup) and File Library (its separate encrypted backup).
