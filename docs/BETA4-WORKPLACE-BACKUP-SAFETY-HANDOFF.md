# Backup-safety preservation / 1.3.1 Beta 4

Before removing workplace hardcoded defaults, this hotfix enriches Master Backup snapshots with all currently available Consultation Form Manager saved group homes and its existing source-coded print profile (organization, program, pharmacy details, and medication-order guidance). It also preserves Monthly Chore Planner starter state and facility name if the tool has never written its state to localStorage. It does not overwrite customized source states; the enrichment is applied to the backup copy only. The Consultation Manager's standalone Full Backup also preserves the template profile after that tool is opened because its hydrated state now carries the same profile.

Existing ShiftView employee records, work locations, rosters, attendance and discipline history remain under the same p8riot:shiftview-schedule: namespace. TransportView remains at transportview-state-v1. Chore Planner remains at p8riot:monthly-chore-planner: and Consultation Manager at consultation-form-manager-state and p8work-consultation-media-v1 IndexedDB. No source client record seeds were introduced. All formerly hardcoded workplace values remain present in source during this safety release. No GitHub upload of private backups is permitted.

Tool-selectable Master Backup can be partial: user must select **all four tools** for a complete Master Backup. File Library uses a separate encrypted .p8lib backup and is not inside the Master Backup. Restore uses existing controls and requires explicit selection and confirmation. A validation of the backup in code cannot prove successful recovery in an employer-managed browser/device. Real work PC and physical usage remain unverified.

Tests: fixture-based scripts exercise preservation of customized staff/facility data, fallback snapshots without saved state, corrupt localStorage fail-closed behavior, MAR missing-media detection, checksums, Master Backup round-trip and restoration adapter compatibility. All tests use synthetic example records and do not contain actual client files.
