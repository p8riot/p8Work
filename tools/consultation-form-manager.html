    Assisted extraction

    Import and Sort Client Info

    Drop screenshots, documents, or pasted text. The app tries to sort records by Patient ID and sends everything to Pending for review before it touches your real client list.

    Weekly MAR PDF, medication import

    Use this for your scanner's weekly MAR PDF. This is a different workflow from importing client demographics. The file may contain multiple clients. Choose the existing client first, then visually select only their MAR order pages. Scans are captured as images, not unreliable medication text.

    No pages are assigned automatically. If the client is not saved yet, add the client in Clients first.

    Upload source files

    EchoVantage diagnosis and payer screenshots can be dropped together. PDFs containing scanned MAR pages are sent to the Weekly MAR PDF section above, not processed as readable text.

    Paste source text

    Useful when you already copied text from a record, or when screenshot reading is blocked by the browser or network.

    Pending / Imported Clients

    Pending is the safety area. These records do not appear on the form until you activate them as new clients or merge them into existing clients.

    Preferences and backup

    Settings

    Appearance

    Themes change the app interface only. The printed Consultation Form stays black and white.

    Consultation form template and pharmacy

    Edit printed wording, pharmacy details, headings and optional sections here. Client details remain editable through Clients; group-home contacts remain editable under Group Homes. These settings are saved locally and included in both Full Backup and p8Work Master Backup. Changing printed text does not change a client's medication orders.

    Changes appear in the printable consultation preview after saving. Long text may prevent the form from fitting on one page.

    Backup and transfer

    Important: client records and saved group homes live in this browser on this device. To use the same clients on another computer or browser, export a Full Backup here, move the backup JSON file, then import it on the other machine.

    Merge recovery

    No merge is currently available to undo.

    Where the client list is saved

    The app saves client records in this browser profile using local storage. That means Chrome on one computer and Edge on another computer will not automatically share the same client list.

    Easy rule: export a Full Backup if you need the client list somewhere else, or before clearing browser data. Uploaded source files are processed temporarily and are not intentionally kept after extraction.

    Important: local browser storage is not encrypted by this app. Use it only on an authorized work device with appropriate device and account protections.

    Client medication record

    Medications

    Import MAR photo(s), EchoVantage timeline screenshots, or enter medication orders manually. MAR page-column capture is preferred when handwriting or layout makes OCR unreliable. The app captures the full medication-information column from each MAR page as a single image, without the staff-initials calendar. This does not identify which orders are current. Pages with likely outside-column handwriting are flagged for a separate, readable close-up. Select the handwritten area on the original scan or explicitly confirm that no close-up is needed. Detection is not perfect, so review the full source page even if it was not flagged. EchoVantage screenshots remain date-filtered draft text only. Compare every imported item against the current authorized record, correct all errors, and check each item before saving. Lists must be rechecked on their day of use.

    Privacy: client records are stored unencrypted in this browser. Enhanced OCR downloads executable code from external providers before processing screenshots in your browser; this has not been approved or verified for protected clinical information. Use only with organizational authorization.

    Choose MAR pages for this client

    Mixed-client safety: a weekly scan can contain multiple clients. Only select pages belonging to the client currently open in the medication editor. Check names and page numbers visually; yellow/green MAR grids are suggested, but every order and handwriting correction must be reviewed before saving. The app checks for dark handwriting beyond the medication column and flags possible amendments. Flagged pages require a review decision; inspect all pages because marks may be missed.

    The selection is NOT a client match. Inspect every chosen page and confirm its owner. Page numbers refer to the uploaded PDF. The importer flags probable writing beyond the medication column. After capture, draw a close-up around the handwritten amendment; the original narrow medication columns remain side-by-side.
